# Skyflo

**The control plane for agentic engineering.**

Skyflo is a local-first mission operating layer for engineering work across code, cloud, CI/CD, and operations. It coordinates coding agents, models, repositories, and tools through governed missions, with approvals, execution evidence, and reviewed memory.

The current product is Skyflo Desktop for macOS. Visit [skyflo.ai](https://skyflo.ai) to explore the product.

[Website](https://skyflo.ai) · [Documentation](https://skyflo.ai/docs) · [Contact](https://skyflo.ai/contact)

## Legacy Kubernetes agent

The earlier open source Kubernetes and CI/CD agent is deprecated and is a separate project from the current Skyflo product. Its source and historical documentation remain in [skyflo-ai/skyflo](https://github.com/skyflo-ai/skyflo).
